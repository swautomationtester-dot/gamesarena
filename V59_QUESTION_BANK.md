# v59 Question Bank

The previous quiz question bank has been removed from the active game flow.

The game now contains exactly 10 supplied India Independence Day questions.
For every new game:

1. The server randomly selects 5 different questions from the 10-question bank.
2. The four answer choices are independently shuffled.
3. The correct answer index is recalculated after shuffling.
4. The selected questions receive the existing 5-question prize values:
   - Q1 ₹1,000
   - Q2 ₹2,000
   - Q3 ₹500
   - Q4 ₹1,000
   - Q5 ₹50,000

Existing database question rows are ignored so old questions cannot reappear.
