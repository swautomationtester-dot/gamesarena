# KBC question sound

The quiz now plays `/assets/kbc-question.mp3` automatically whenever a new question loads on the participant and Quiz TV screens.

Place your `kbc-question.mp3` file at:

`public/assets/kbc-question.mp3`

The browser may block autoplay until the page has received a user interaction. The existing TV/participant page controls can be used to enable sound if the browser requires a gesture.
