# GamesArena Common Modern UI

All non-home pages now receive the same animated GamesArena header and footer through:
- `/common-ui.css`
- `/common-ui.js`

The Home page keeps its dedicated modern hero header/footer.

The shared header provides Home, Host Console and Payment Inventory navigation.
The shared footer provides consistent branding/navigation.

The global UI is responsive and respects `prefers-reduced-motion`.
