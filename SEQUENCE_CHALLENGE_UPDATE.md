# Fastest Finger — Sequence Challenge Update

- Fastest Finger time: **15 seconds** after the existing 5-second ready countdown.
- Game type: **Sequence Challenge**.
- Difficulty: **HARD**.
- Challenge: 8 unique three-digit numbers are shuffled for each round.
- Objective: select the numbers from **LOWEST → HIGHEST** as quickly as possible.
- The first selected player to complete all 8 correctly wins.
- Wrong selections are rejected without advancing progress.
- Host, Participant and TV show the same challenge and live progress.
- Host sees the challenge values and 15-second status.
- Participant buttons lock as each correct number is selected.
- TV displays each selected player's progress as a live 0/8 → 8/8 tracker.
- Fastest Finger QR/session validation remains restricted to the selected 7 players.
- Game Rules on Host, Participant and TV now describe the 15-second Sequence Challenge.
