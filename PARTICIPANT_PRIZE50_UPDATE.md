# GamesArena Participant + Prize Ladder Update

Applied to the latest GamesArena Host/CardMatch build.

## Participant screen
- After successful registration, the registration form, KBC entry branding, and connection panel are hidden.
- The participant sees only:
  - Username
  - Room number
  - Registration/waiting message
  - Prize ladder
- The active quiz controls remain hidden until the host starts the game.
- The active quiz view is restored automatically when the participant becomes a contestant or the Fastest Finger phase starts.
- Added responsive modern styling and subtle entrance/pulse animations.

## Prize ladder
The authoritative server and all visible ladder screens now use:

`₹10, ₹20, ₹30, ₹40, ₹50, ₹50, ₹50, ₹50, ₹50, ₹50`

- Minimum prize: ₹10
- Maximum prize: ₹50
- Q4 Safe Money: ₹40
- Q8 Safe Money: ₹50
- Q10 Final: ₹50

Updated consistently in the server, participant screen, Host Console, and Quiz TV.
