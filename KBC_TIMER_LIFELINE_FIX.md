# GamesArena KBC Timer + Lifeline Fix

## Included
- 30-second server-controlled timer for each of the 5 KBC questions.
- Timer starts when each question becomes active.
- Host can manually **Hold Timer** and **Resume Timer** while using 50:50 / Phone-a-Friend or for any other pause.
- Locking an answer pauses the question clock until the host approves/rejects it.
- If the 30-second question timer reaches zero without an answer, the contestant is eliminated and the next Fastest Finger round starts.
- Audience Poll is host-controlled.
- Host approval of an Audience Poll request does not start the poll timer.
- Host must explicitly click **Start Audience Poll (30s)**.
- Audience Poll has its own 30-second timer.
- Starting the Audience Poll pauses the main question timer.
- When the Audience Poll is stopped or its 30 seconds expire, the question timer resumes with the remaining time.
- Question timer is shown on Host, contestant and TV screens.
- Audience Poll timer is shown on Host, contestant and TV screens.
- 50:50 removed options are now reflected on the TV screen as **OPTION REMOVED**, in sync with the contestant view.
