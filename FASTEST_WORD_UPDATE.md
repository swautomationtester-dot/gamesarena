# Fastest Word Update

- Replaced the Fastest Finger sequence game with a Medium Word Scramble.
- Exactly 7 eligible players are selected when available.
- Words are 8–10 letters and use company/event-themed vocabulary.
- Each round gives a 5-second ready countdown and a 10-second answer window.
- The first correct submitted word wins; incorrect submissions can be retried while time remains.
- TV shows the scrambled letters, live response status and winner.
- Winner screen shows name, response time in seconds, audience applause and a KBC-style hot-seat visual.
- Added `public/assets/audience-clapping.wav`.
- Mobile-responsive contestant UI with large scramble tiles, text input and submit button.
- Cache-busted JS/CSS query strings were updated for Hostinger deployment.
